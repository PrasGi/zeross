# Cryptography

Goal: standard, correctly used primitives; unpredictable tokens; constant-time secret comparison;
verified signatures; TLS actually verified. ASVS V6 (stored cryptography), V9 (communications).
Never roll your own; if the code implements an algorithm or protocol by hand, that alone is a finding.

## Randomness for anything secret

| Language | Insecure (flag for tokens, IDs that grant access, OTPs, salts, nonces) | Secure |
|---|---|---|
| Node | `Math.random()`, `Date.now()`-based IDs, `shortid`/`nanoid` non-secure variant `nanoid/non-secure` | `crypto.randomBytes`, `crypto.randomUUID`, `crypto.randomInt`, `crypto.getRandomValues`, `nanoid` |
| Python | `random.*`, `uuid.uuid1()` | `secrets.token_urlsafe`, `secrets.token_bytes`, `secrets.randbelow`, `uuid.uuid4()` |
| Go | `math/rand` | `crypto/rand` (`rand.Read`, `rand.Text` in Go ≥ 1.24) |
| PHP | `rand`, `mt_rand`, `uniqid`, `lcg_value`, `str_shuffle` | `random_bytes`, `random_int`, `Str::random` (Laravel, CSPRNG) |
| Java/Kotlin | `java.util.Random`, `Math.random`, `ThreadLocalRandom` | `SecureRandom` |

- [ ] Session IDs, reset/verify/invite tokens, API keys: ≥ 128 bits of CSPRNG entropy.
- [ ] OTP digits from `randomInt(0, 10**6)`-style CSPRNG, not `Math.floor(Math.random()*…)`.
- [ ] UUIDv4 is fine as an unguessable identifier (122 random bits) when generated by a CSPRNG; UUIDv1/v7 are not secrets.

## Comparing secrets

- [ ] Tokens, HMACs, API keys, webhook signatures compared in constant time:
  Node `crypto.timingSafeEqual(a, b)` (check equal length first, compare Buffers);
  Python `hmac.compare_digest`; Go `subtle.ConstantTimeCompare` / `hmac.Equal`;
  PHP `hash_equals`; Java `MessageDigest.isEqual`.
- [ ] Smells: `===`, `==`, `strcmp`, `.equals()` on secrets. PHP loose `==` on hashes (`"0e1…" == "0e2…"` is true): High.
- [ ] Better: look tokens up by a hash (store `sha256(token)`), which avoids timing issues on lookup.

## Hashing

- [ ] Passwords: argon2id / bcrypt / scrypt only (see `authn.md`).
- [ ] MD5/SHA-1 never for security (signatures, integrity against attackers, password storage, token derivation). Fine for non-security checksums and cache keys.
- [ ] Integrity/authenticity needs a key: HMAC-SHA256, not `sha256(secret + data)` (length extension) and not a plain hash of the data.

## Webhook and request signatures

- [ ] Signature verified **before** any processing, with the provider SDK where available (Stripe `constructEvent`, Svix, GitHub `X-Hub-Signature-256`, Slack signing secret, Shopify HMAC).
- [ ] HMAC computed over the **raw** request body bytes. Express: `express.raw({ type: 'application/json' })` on that route, before `express.json()`; Next.js route handler: `await req.text()` before parsing; Nest: `rawBody: true`; FastAPI: `await request.body()`; Laravel: `$request->getContent()`; Go: read `r.Body` once.
- [ ] Timestamp checked within a tolerance; event ID deduplicated (replay).
- [ ] Missing or invalid signature → 401/400 and no side effects. A disabled check behind a flag that defaults on in non-local envs is High.

## Encryption

- [ ] Authenticated encryption: AES-256-GCM or ChaCha20-Poly1305 via the platform library (Node `crypto` `aes-256-gcm`, Go `crypto/cipher` GCM, Python `cryptography` `AESGCM`/Fernet, libsodium, Java `AES/GCM/NoPadding`, Laravel `Crypt`).
- [ ] Never: ECB (`aes-*-ecb`, Java `"AES"` defaults to ECB), CBC without a MAC, DES/3DES/RC4, `crypto.createCipher` (deprecated, MD5-based key derivation).
- [ ] Nonce/IV unique per encryption with the same key (random 96-bit for GCM); never constant or reused. GCM tag verified (`setAuthTag` before `final`).
- [ ] Keys from a secret manager/env, correct length, never derived from a password without a KDF (PBKDF2/scrypt/argon2 with salt), rotation possible (key IDs).
- [ ] Base64/hex/ROT/XOR are encodings, not encryption.
- [ ] JWT/JWE: see `authn.md` for algorithm pinning; HS256 secrets ≥ 32 random bytes.

## TLS and certificate verification

Flag any of these outside test code:

```text
rejectUnauthorized: false        NODE_TLS_REJECT_UNAUTHORIZED=0       https.Agent({ rejectUnauthorized: false })
InsecureSkipVerify: true         verify=False (requests/httpx)        ssl._create_unverified_context
CURLOPT_SSL_VERIFYPEER => false  CURLOPT_SSL_VERIFYHOST => 0           'verify' => false (Guzzle)
TrustManager that accepts all    HostnameVerifier returning true      sslmode=disable / tls=false to remote DB
```

- [ ] Outbound connections to DBs, queues and APIs over the network use TLS with verification.

## Severity guide

Predictable reset/session/API tokens: **Critical/High**. Unverified webhook signatures acting on
money or state: **High**. Non-constant-time compare of a high-entropy token: **Low/Medium**
(remote timing is hard; High for PHP loose `==` on hashes). TLS verification disabled in
production paths: **High**. ECB / unauthenticated CBC on sensitive data: **High/Medium**.
Custom crypto: **High** until proven otherwise.
